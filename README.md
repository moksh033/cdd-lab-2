## Experiment 2 Overview
This repository documents hands-on operations for synchronizing local Git repositories with a remote GitHub origin:
- Setting up and cloning a remote repository over HTTPS (`git clone https://github.com/moksh033/cdd-lab-2.git`)
- Verifying remote tracking endpoints using `git remote -v`
- Committing source deliverables and pushing snapshots via `git push origin main`
- Inspecting incoming remote refspecs via `git fetch` and integrating changes via `git pull`
